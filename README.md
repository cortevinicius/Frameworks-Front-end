# 📘 Frameworks Front-end — Conteúdos da Disciplina

Este repositório reúne o material da disciplina, conteúdos teóricos, planos de aula, apresentações, atividades e exercícios da disciplina **Frameworks Front-end**.

O objetivo deste repositório é centralizar e organizar os conteúdos desenvolvidos ao longo da disciplina, servindo como apoio ao processo de ensino-aprendizagem, revisão dos estudos, desenvolvimento de aplicações web e consulta acadêmica.

---

## 🎯 Objetivo da Disciplina

A disciplina de Frameworks Front-end tem como finalidade desenvolver competências para a programação de aplicações web modernas, utilizando tecnologias e frameworks amplamente utilizados no desenvolvimento de interfaces para internet.

Ao longo da disciplina, os estudantes aprendem a configurar ambientes de desenvolvimento, utilizar frameworks para CSS e JavaScript, aplicar boas práticas de desenvolvimento Front-end e construir aplicações responsivas com foco na experiência do usuário.

## 💡 Capacidades Desenvolvidas

Ao final da disciplina, espera-se que o estudante seja capaz de:

- Configurar ambientes de desenvolvimento para aplicações Web;
- Aplicar tecnologias Front-end na construção de interfaces;
- Utilizar editores modernos para criação e correção de documentos;
- Definir frameworks adequados às necessidades do projeto;
- Desenvolver aplicações web responsivas considerando princípios de UX.

Além das competências técnicas, serão desenvolvidas competências relacionadas a:

- Ética profissional;
- Pensamento crítico e inovação;
- Resolução de problemas complexos;
- Trabalho em equipe.
