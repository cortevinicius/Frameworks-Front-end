# ReactLab — Fundamentos do React

## Descrição

O ReactLab é uma aplicação web desenvolvida com React para apresentar os principais conceitos utilizados no desenvolvimento de interfaces front-end. O projeto funciona como um guia de estudos com explicações e exemplos práticos.

## Funcionalidades

- Apresentação dos principais conceitos do React.
- Cards com explicações e exemplos de código.
- Destaque visual para conceitos essenciais.
- Navegação entre a introdução e a seção de conceitos.
- Layout responsivo para computadores, tablets e celulares.

## Tecnologias utilizadas

- React
- JavaScript
- JSX
- CSS
- Vite

## Conceitos React aplicados

- **JSX:** escrita de estruturas semelhantes ao HTML dentro do JavaScript.
- **Componentes:** criação de componentes reutilizáveis, como `ConceptCard`.
- **Props:** passagem de dados para os componentes.
- **Virtual DOM:** conceito relacionado à atualização da interface pelo React.
- **Listas e Keys:** utilização de `map()` para renderizar os cards e `key` para identificar cada item.
- **Renderização condicional:** utilização de condições para exibir o destaque "Essencial".

## Como executar o projeto

1. Instale o Node.js.
2. Abra o terminal na pasta do projeto.
3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Abra no navegador o endereço apresentado no terminal.
