# Atividade 02 — React e Vercel

## 📚 Resumo da Aula

Nesta aula foram estudados e aplicados conceitos fundamentais do **React**, uma biblioteca JavaScript utilizada para o desenvolvimento de interfaces de usuário.

Durante a atividade, foi desenvolvido o **TaskFlow**, uma aplicação para gerenciamento de tarefas utilizando **React e Vite**.

Também foram trabalhados conceitos de organização de componentes, JSX, estados, eventos e reutilização de componentes.

Além do desenvolvimento da aplicação, a atividade envolveu o uso do **Git e GitHub** para versionamento do projeto e a publicação da aplicação utilizando a **Vercel**.

## 🎯 Objetivos

- Aprender os conceitos básicos do React;
- Criar e utilizar componentes;
- Trabalhar com JSX;
- Utilizar estados e eventos;
- Organizar uma aplicação React;
- Utilizar o Vite;
- Versionar o projeto com Git e GitHub;
- Realizar o deploy utilizando a Vercel.

## 🛠️ Tecnologias utilizadas

- React
- Vite
- JavaScript
- HTML5
- CSS3
- ESLint
- Git
- GitHub
- Vercel

## 📌 Projeto desenvolvido

O **TaskFlow** é uma aplicação de gerenciamento de tarefas desenvolvida com React.

A aplicação utiliza componentes para separar as funcionalidades e facilitar a organização e manutenção do código.

## 🚀 Deploy

A aplicação foi publicada utilizando a **Vercel**, permitindo que o projeto fosse acessado pela internet.
