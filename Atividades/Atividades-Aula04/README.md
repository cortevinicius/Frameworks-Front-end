## Resumo das APIs

* **PokeAPI:** utilizada para obter informações sobre Pokémon.
* **TMDB API:** utilizada para obter informações sobre filmes e séries.
* **OpenWeatherMap API:** utilizada para obter informações meteorológicas.
* **OpenWeather API:** utilizada para consultar dados de clima e previsão do tempo.
* **Spoonacular API:** utilizada para buscar informações e receitas.
* **TheMealDB API:** utilizada para obter receitas e informações sobre refeições.
