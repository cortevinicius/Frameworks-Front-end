# Projetos com APIs — Aula 04

## 📚 Atividade 02

Nesta aula, foi desenvolvida uma atividade prática envolvendo a criação e o consumo de uma API.

O objetivo foi criar uma **API utilizando Express**, disponibilizando uma rota para consulta de **data e hora**, e realizar o deploy da aplicação utilizando o **Render**, permitindo que a API fosse acessada pela internet.

Em seguida, foi desenvolvido um **frontend separado**, responsável por consumir a API e apresentar na tela as informações de data e hora obtidas.

Também foi trabalhada a organização dos projetos em diferentes repositórios no GitHub, separando a **API**, o **frontend** e os demais projetos da atividade.

### 🛠️ Tecnologias utilizadas

- Node.js
- Express
- JavaScript
- React
- Render
- Vercel
- Git e GitHub
- API REST

## 🌐 Resumo das APIs

- **PokeAPI:** utilizada para obter informações sobre Pokémon.

- **Spoonacular API:** utilizada para buscar informações e receitas.
- **TheMealDB API:** utilizada para obter receitas e informações sobre refeições.

## 🎯 Objetivo da Aula

A atividade teve como objetivo colocar em prática o desenvolvimento e consumo de **APIs**, trabalhando desde a criação de uma API com Express até o seu **deploy online** e integração com uma aplicação frontend.

Também foram praticados conceitos de **React, requisições HTTP, integração entre frontend e backend, Git, GitHub, Render e Vercel**.
