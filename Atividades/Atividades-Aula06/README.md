# Aula 06 – Projetos Front-End

## Projeto Integrador – GastroMatch

### Objetivo

Aplicar os conceitos de gestão de projetos Front-End apresentados em aula, utilizando o Projeto Integrador GastroMatch como referência.

### Projeto

O **GastroMatch** é uma plataforma gastronômica que conecta usuários, receitas, chefs, restaurantes e nutricionistas.

**Repositório do projeto:**

https://github.com/GastroMatch-PI/GastroMatch

### Gestão do Projeto

O GastroMatch utiliza o GitHub para organizar e acompanhar o desenvolvimento do projeto.

As ferramentas e práticas utilizadas incluem:

- **Backlog:** organização das funcionalidades e atividades necessárias para o projeto.
- **Prioridades:** classificação das tarefas conforme sua importância.
- **Tarefas:** divisão das funcionalidades em Issues.
- **Kanban:** acompanhamento visual do andamento das atividades.
- **Branches:** organização do desenvolvimento por meio de branches individuais e permanentes.
- **Pull Requests:** revisão e integração das alterações realizadas pelos integrantes.

### Organização das Branches

O projeto utiliza três tipos de branches:

- `main`: versão estável do projeto.
- `develop`: integração das funcionalidades desenvolvidas pela equipe.
- `feature/nome`: branch individual de cada integrante.

### Critérios de Conclusão

Uma atividade pode ser considerada concluída após:

- Implementação da funcionalidade.
- Realização dos testes necessários.
- Revisão do código.
- Verificação da responsividade, quando aplicável.
- Integração das alterações ao projeto.

### Conclusão

O Projeto Integrador GastroMatch utiliza práticas de gerenciamento de projetos Front-End para organizar as atividades, distribuir responsabilidades, acompanhar o progresso e facilitar a colaboração entre os integrantes da equipe.

A utilização do GitHub permite centralizar as tarefas, acompanhar as entregas e manter um fluxo organizado de desenvolvimento.
