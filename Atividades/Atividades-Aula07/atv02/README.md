# Atividade 02 — Tailwind CSS

## 📌 Sobre o projeto

Este projeto foi desenvolvido para a atividade da disciplina de **Frameworks Front-end**.

O objetivo é utilizar o **Tailwind CSS** para construir uma interface web utilizando classes utilitárias para cores, tipografia, espaçamentos, dimensões, bordas, Flexbox, Grid e responsividade.

A aplicação apresenta um dashboard com informações sobre algumas tecnologias utilizadas no desenvolvimento web.

## 🛠️ Tecnologias utilizadas

* HTML5
* Tailwind CSS
* JavaScript/CDN
## 🎨 Classes Tailwind utilizadas

| Classe            | Função                                  |
| ----------------- | --------------------------------------- |
| `min-h-screen`    | Define a altura mínima da página        |
| `bg-gray-100`     | Define a cor de fundo                   |
| `text-gray-800`   | Define a cor do texto                   |
| `bg-blue-700`     | Define o fundo azul                     |
| `text-white`      | Define o texto branco                   |
| `px-6`            | Define espaçamento horizontal           |
| `py-5`            | Define espaçamento vertical             |
| `shadow-md`       | Adiciona sombra                         |
| `max-w-6xl`       | Define a largura máxima                 |
| `mx-auto`         | Centraliza o conteúdo                   |
| `flex`            | Ativa o Flexbox                         |
| `flex-col`        | Organiza os elementos em coluna         |
| `md:flex-row`     | Organiza em linha em telas médias       |
| `justify-between` | Distribui os elementos                  |
| `items-center`    | Alinha os elementos ao centro           |
| `gap-4`           | Define espaçamento entre elementos      |
| `text-3xl`        | Define tamanho do texto                 |
| `font-bold`       | Deixa o texto em negrito                |
| `bg-white`        | Define fundo branco                     |
| `p-6`             | Define espaçamento interno              |
| `rounded-xl`      | Arredonda as bordas                     |
| `border`          | Adiciona uma borda                      |
| `grid`            | Ativa o CSS Grid                        |
| `grid-cols-1`     | Define uma coluna                       |
| `sm:grid-cols-2`  | Define duas colunas em telas pequenas   |
| `lg:grid-cols-4`  | Define quatro colunas em telas grandes  |
| `gap-6`           | Define espaçamento entre os elementos   |
| `hover:shadow-lg` | Aumenta a sombra ao passar o mouse      |
| `transition`      | Adiciona uma transição                  |
| `w-12`            | Define a largura                        |
| `h-12`            | Define a altura                         |
| `text-xl`         | Define o tamanho do texto               |
| `mb-4`            | Define margem inferior                  |
| `leading-relaxed` | Define espaçamento entre linhas         |
| `rounded-full`    | Deixa as bordas totalmente arredondadas |
| `text-xs`         | Define texto pequeno                    |
| `font-semibold`   | Define o peso da fonte                  |
